# Contrata Sul — Versão V5

**Comece pelo arquivo `LEIA-PRIMEIRO-V5-CURRICULOS.md`.** Ele explica todas as etapas de publicação, configuração do Firebase Authentication anônimo, Storage, Firestore Rules e Storage Rules.

Esta versão atualiza o visual de todas as telas e exige currículo PDF/DOCX na candidatura. O site público continua em `index.html`, o painel administrativo em `admin.html`, o portal empresarial em `portal-empresa.html` e o formulário em `candidatar.html`.

**IMPORTANTE: é obrigatório publicar as novas `firestore.rules` E as novas `storage.rules`.** Não basta enviar os arquivos ao GitHub Pages.

Antes de publicar: faça backup dos dados existentes, verifique custos do Firebase Storage e teste com uma vaga fictícia.
