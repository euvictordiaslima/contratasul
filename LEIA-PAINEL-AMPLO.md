# Contrata Sul — Painel administrativo amplo

Esta edição reorganiza **somente a interface do painel**, preservando as funções e a conexão com Firebase já existentes.

## Novidades
- Visão geral como tela inicial.
- Layout de largura fluida, até 1900px, aproveitando monitores grandes.
- Menu lateral mais espaçoso, fixo durante a rolagem em desktop.
- Área de trabalho independente, cartões maiores e separação clara entre módulos.
- Formulário e listagem de vagas com proporções ajustadas; em telas médias, empilhados para evitar aperto.
- Navegação horizontal adaptada para celulares.

## Publicação
Substitua os arquivos do site pela nova versão. Limpe o cache com Ctrl+Shift+R.

## Firestore Rules
**Não precisa atualizar as regras** para esta mudança visual. Mantenha as regras corrigidas da versão anterior.

## Limitações
A versão preserva os recursos do projeto anterior, sem acrescentar serviços pagos. Os fluxos de autenticação, backup e recuperação não foram validados no Firebase real. Faça backup antes de atualizar.
