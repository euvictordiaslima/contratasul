# Contrata Sul V6 no Android e no iPhone

Primeiro publique os arquivos V6 no endereço `https://euvictordiaslima.github.io/contratasul/`.

- **Android (PWA)**: Chrome → menu de três pontos → Instalar app / Adicionar à tela inicial.
- **iPhone (PWA)**: Safari → Compartilhar → Adicionar à Tela de Início.
- **APK anterior**: é um aplicativo Android que abre o endereço publicado; em geral, o novo visual aparece após publicar a V6 e atualizar o cache. Não é necessário outro APK apenas para trocar o CSS do site.

**Rules:** o aplicativo em si não precisa de regras extras. Para que a candidatura com currículo funcione na V6, é obrigatório publicar o novo `firestore.rules` e habilitar Authentication Anônimo. **Não configure Firebase Storage, não publique `storage.rules` e não ative faturamento apenas por causa desta funcionalidade.**
